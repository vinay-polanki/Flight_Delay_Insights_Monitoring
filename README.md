
# Flight Delay Insights Monitoring

## Project Overview
This project is being developed as part of the **CIS 695 Comprehensive Project** for the Master of Science in Information Systems (MSIS) program at Murray State University. Flight delays impact both passengers and airlines, causing missed connections, financial losses, and scheduling issues. This project aims to develop a real-time flight delay monitoring dashboard using GoFlightLabs API to fetch live flight delay data. The dashboard will provide users with interactive visualizations to analyze delay trends across different airlines and airports.

## Features
- **Real-time Flight Delay Tracking**: Retrieves live delay data from GoFlightLabs API.
- **Interactive Dashboard**: Uses Power BI for data visualization.
- **Filter & Search Options**: Users can filter delays by airport, airline, and delay causes (weather, air traffic congestion, operational issues, etc.).
- **Data Processing**: Python and Pandas are used for API integration and data structuring.

## Technology Stack
- **API Integration**: GoFlightLabs API
- **Backend Processing**: Python, Pandas
- **Visualization**: Power BI
- **Web Framework (Optional)**: Flask (if needed for hosting UI)

## Installation & Usage
1. Clone this repository:
   ```sh
   git clone https://github.com/vinay-polanki/Flight_Delay_Insights_Monitoring.git
   ```
2. Install dependencies:
   ```sh
   pip install pandas requests flask  # If Flask-based UI is used
   ```
3. Set up API access by obtaining an API key from [GoFlightLabs](https://goflightlabs.com/).
4. Run the Python script to fetch flight delay data.
5. Use Power BI to visualize the processed data.
